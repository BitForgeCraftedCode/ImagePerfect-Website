Image Perfect

A lightning-fast, privacy-first image library built for massive photo collections. Scan, browse, tag, and organize photos with zero cloud, zero lock-in, and zero lag — on Windows or Linux.


Key Features

⚡
Blazing Fast Metadata Scanning

Optimized parallel scanning designed for huge libraries.

🔍
Powerful Searching & Tagging

Add tags and ratings to images and folders, filter, and navigate large collections effortlessly.

🖼️
Local & Private

No cloud, no uploads, no tracking.
Your entire library lives on your machine — exactly where it belongs.

📁
Folder-Based Organization

Manage your folder structure directly inside the app: move, delete, re-organize, and set cover images with full file-system mirroring.

📸
Shotwell Import Support

Reads Shotwell-written metadata (tags + ratings) so you can migrate cleanly on Linux.

💻 🐧
Cross-Platform

Runs on Windows and Ubuntu/Linux, backed by .NET 8 and Avalonia UI.

📦
Standard Formats

Supports JPEG, PNG, and GIF, with fast loading and large previews.

🧭
Clean Modern Interface

A responsive UI that stays fast even with large directories.

🖼️
Large Thumbnails

True large previews — from 400px up to 600px — without writing thumbnails to disk.
